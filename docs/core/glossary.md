# Glossary

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines shared vocabulary for PL-OS contributors.

## Scope

- Terms
- Abbreviations
- Governance vocabulary
- Brand vocabulary

## Requirements

- Terms must be defined before being used as standards.
- Avoid overloaded terms when a clearer phrase exists.

## Implementation Guidance

- Add glossary entries with new domain-specific standards.
- Prefer explicit definitions over assumptions.

## Acceptance Criteria

- A new contributor can understand core vocabulary.
- Terms remain consistent across volumes.
