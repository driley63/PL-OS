# Core Roadmap

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines the ordered evolution of PL-OS after the initial baseline.

## Scope

- Foundation
- Brand
- Design
- Engineering
- Product
- AI
- Production

## Requirements

- Core must precede volume expansion.
- Brand and design tokens should stabilize before broad UI implementation.

## Implementation Guidance

- Use milestones to order work, not to block valuable patches.
- Update the roadmap through release notes.

## Acceptance Criteria

- A contributor can see what is next.
- Volume statuses are visible.
