# Versioning

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines semantic versioning for PL-OS releases.

## Scope

- Patch
- Minor
- Major
- Pre-release
- Deprecation

## Requirements

- Breaking changes require a major version.
- Additive standards require a minor version.
- Clarifications use patch versions.

## Implementation Guidance

- Version individual specs when useful, but publish operating system releases as bundles.
- Record migration notes for implementers.

## Acceptance Criteria

- Reviewers can classify a change type.
- Release manifests identify included versions.
