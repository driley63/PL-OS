# PL-OS Core

PL-OS Core is the constitution for Plectara's operating system. It defines why the system exists, how decisions become standards, how releases are cut, and what cannot be compromised.

## Contents

- `SPEC.md`: complete Core specification
- `constitution.md`: founding authority and scope
- `mission.md`: mission and intended audience
- `philosophy.md`: product philosophy and decision lens
- `principles.md`: product principles
- `governance.md`: lifecycle, roles, and approvals
- `versioning.md`: semantic versioning model
- `release-process.md`: release assembly and acceptance
- `adr-process.md`: permanent decision records
- `rfc-process.md`: proposal workflow
- `repository-conventions.md`: file, naming, and structure conventions
- `quality-standards.md`: acceptance criteria for every addition
- `non-negotiables.md`: stable boundaries
- `roadmap.md`: roadmap for future volumes
- `glossary.md`: common terms

## Authority

If two PL-OS documents conflict, Core wins unless an approved ADR explicitly supersedes the relevant section.
