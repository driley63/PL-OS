# Repository Conventions

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines naming, file layout, and documentation conventions.

## Scope

- Markdown source
- Kebab-case paths
- Numbered records
- Release folders
- Asset source

## Requirements

- Markdown files must be the source of truth.
- Filenames should be stable and descriptive.
- Generated artifacts must not replace source content.

## Implementation Guidance

- Use lowercase directories.
- Use numbered prefixes only where ordering matters.
- Prefer links to duplicated content.

## Acceptance Criteria

- A new file has a predictable location.
- Specs can be discovered from the docs nav.
