# Release Process

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines how official PL-OS releases are assembled.

## Scope

- Release checklist
- Manifest
- Notes
- Migration guidance
- Artifacts

## Requirements

- Every release must include a manifest, notes, and known limitations.
- Release notes must separate added, changed, deprecated, and removed items.

## Implementation Guidance

- Cut releases from reviewed main branch content.
- Avoid changing released files without a patch release.

## Acceptance Criteria

- A release can be reproduced from repository content.
- Consumers can tell what changed.
