# RFC Process

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines how proposals are reviewed before they become decisions.

## Scope

- Problem framing
- Proposal
- Alternatives
- Impact
- Open questions

## Requirements

- RFCs must identify affected specs and expected migration impact.
- Accepted RFCs should link to resulting ADRs.

## Implementation Guidance

- Use RFCs to reduce premature locking.
- Close abandoned RFCs with a reason.

## Acceptance Criteria

- A proposal can be reviewed without private context.
- Open questions are explicit.
