# ADR Process

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines when and how permanent decision records are created.

## Scope

- ADR triggers
- Numbering
- Status
- Supersession
- Consequences

## Requirements

- Major naming, token, architecture, governance, AI, or safety decisions require ADRs.
- ADRs are append-only except for status updates.

## Implementation Guidance

- Prefer concise ADRs with real alternatives.
- Do not use ADRs as broad essays.

## Acceptance Criteria

- A new decision has context, decision, alternatives, and consequences.
- Superseded decisions remain readable.
