# Governance

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines the lifecycle for adding, changing, releasing, and deprecating standards.

## Scope

- Statuses
- Roles
- Review gates
- Decision flow
- Deprecation

## Requirements

- Significant changes require RFC review.
- Accepted decisions require ADRs.
- Released content requires release notes.

## Implementation Guidance

- Keep governance lightweight but explicit.
- Prefer written traceability over memory.

## Acceptance Criteria

- A change can be placed in the correct status.
- A release can be audited from RFC to ADR to spec.
