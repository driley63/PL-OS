# PL-OS Constitution

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines the authority, scope, and operating rules of PL-OS.

## Scope

- Core authority
- Conflict resolution
- Scope boundaries
- Release accountability

## Requirements

- Core is authoritative when documents conflict.
- Approved ADRs may supersede specific Core sections.
- Released artifacts must be preserved for history.

## Implementation Guidance

- Use Core as the first reference during review.
- Record exceptions in ADRs.
- Do not use informal chat decisions as released standards until committed.

## Acceptance Criteria

- A contributor can determine whether a change needs an RFC.
- A maintainer can identify the authoritative source for a standard.
