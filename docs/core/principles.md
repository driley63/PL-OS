# Product Principles

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines the seven principles used to evaluate product and system changes.

## Scope

- Understanding
- Action
- Clarity
- Evidence
- Consistency
- Accessibility
- Implementation

## Requirements

- Each major change must name the principle it primarily supports.
- Principle conflicts must be resolved in the RFC or ADR.

## Implementation Guidance

- Use principles as review criteria, not slogans.
- When two principles conflict, document the tradeoff.

## Acceptance Criteria

- PRs identify relevant principles.
- ADR consequences mention affected principles.
