# Contribution Model

Status: Released
Owner: PL-OS Maintainers
Version: 1.0.0
Last updated: 2026-08-02

## Purpose

Defines how contributors participate in the PL-OS workflow.

## Scope

- Roles
- Reviews
- Ownership
- Issue templates
- Pull requests

## Requirements

- Contributions must use the appropriate template.
- Review should focus on the product impact and implementation path.

## Implementation Guidance

- Keep discussion attached to the artifact being changed.
- Use RFCs for uncertain proposals.

## Acceptance Criteria

- A contributor can open the correct issue type.
- A maintainer can evaluate readiness.
