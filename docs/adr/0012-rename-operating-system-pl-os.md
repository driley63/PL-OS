# ADR-0012: Rename the operating system PL-OS

Status: Accepted for repository implementation
Date: 2026-09-04

## Decision

The product remains **Plectara**. Its internal operating system and canonical specification collection is **PL-OS**, expanded as **Plectara Operating System**. The owner proposed this name while requesting completion of the rebrand.

This supersedes the LIQ OS display name in ADR-0005 and the repository-system naming statement in ADR-0011. The versioned operating model, governance, and specification hierarchy remain unchanged.

## Scope

Use PL-OS in current documentation, site metadata, release templates, and contributor guidance. Preserve historical ADR and release text. Keep `LIQ-OS` as the existing directory and GitHub repository slug for compatibility; renaming or redirecting hosted repositories is a separate operation. Existing `liq` package/API identifiers and legacy token aliases are not automatically renamed.

PL-OS is a documentation/system name, not a separate consumer product or legal entity. No incorporation, domain purchase, trademark filing, publishing, or deployment is performed by this decision.
