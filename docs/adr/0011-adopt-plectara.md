# ADR-0011: Adopt Plectara and the woven-person identity

Status: Accepted for repository implementation
Date: 2026-09-04

## Decision

The product brand is Plectara, pronounced plek-TAIR-uh. The owner selected the woven-person logo and muted copper, teal, jade, slate, ink, and ivory palette. The distinct strands form a human figure: daily signals become a more complete understanding of the person.

This decision supersedes the product name in ADR-0001 and the signature gradient in ADR-0004. Their original records and release archives remain historical evidence. The initial decision retained LIQ OS as the system identifier. ADR-0012 subsequently adopts PL-OS as its display name; repository URLs and package identifiers remain unchanged.

The Inter typography system, component shapes, spacing, radii, motion, and interaction patterns remain in place. Component colors migrate to the Plectara semantic palette. AI Purple remains reserved under ADR-0003.

## Artwork implementation

The approved generated PNG is retained in the brand kit as a reference. The vector implementation is a geometric reconstruction with lettering recovered from the approved image, not an outlined Inter substitute or a lossless PNG conversion. The owner approved the final vector geometry, consistent separation channels, and restored lettering on 2026-09-04. This authorized reconstruction establishes the current source artwork. Future derivatives must use these SVG sources; do not retrace exported PNGs.

## Consequences

Brand Identity advances to v2.0.0. Legacy token aliases continue to resolve so component consumers can migrate incrementally. No legal entity type is selected by this decision. Naming approval does not constitute incorporation, a domain purchase, or trademark registration; prior availability checks remain preliminary.
