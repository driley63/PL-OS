# Change A Specification

## Steps

1. Classify the change type.
2. Update requirements and implementation guidance.
3. Update examples.
4. Update release notes.
5. Link RFCs and ADRs.

## Exit Criteria

- The change can be reviewed from repository content.
- Related specs, ADRs, RFCs, assets, and release notes are updated.
- The change is consistent with PL-OS Core.
