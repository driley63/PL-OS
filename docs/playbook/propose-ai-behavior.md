# Propose Ai Behavior

## Steps

1. Start with user benefit.
2. State evidence and confidence model.
3. Define failure states.
4. Check non-diagnostic language.
5. Request AI safety review.

## Exit Criteria

- The change can be reviewed from repository content.
- Related specs, ADRs, RFCs, assets, and release notes are updated.
- The change is consistent with PL-OS Core.
