# Add A Brand Asset

## Steps

1. Keep source assets separate from generated exports.
2. Update the asset inventory.
3. Verify clear space and minimum sizes.
4. Generate platform variants.
5. Record the change in release notes.

## Exit Criteria

- The change can be reviewed from repository content.
- Related specs, ADRs, RFCs, assets, and release notes are updated.
- The change is consistent with PL-OS Core.
