# Create An Rfc

## Steps

1. Describe the problem before the solution.
2. Identify affected volumes.
3. Name unresolved questions.
4. Ask for review before implementation.
5. Close with an outcome.

## Exit Criteria

- The change can be reviewed from repository content.
- Related specs, ADRs, RFCs, assets, and release notes are updated.
- The change is consistent with PL-OS Core.
