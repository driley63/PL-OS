# Add A Design Token

## Steps

1. Start with a semantic need.
2. Add primitive and semantic values.
3. Map to Flutter and CSS.
4. Document accessibility impact.
5. Add migration guidance if replacing a token.

## Exit Criteria

- The change can be reviewed from repository content.
- Related specs, ADRs, RFCs, assets, and release notes are updated.
- The change is consistent with PL-OS Core.
