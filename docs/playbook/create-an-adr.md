# Create An Adr

## Steps

1. Confirm the decision is durable.
2. Start from the ADR template.
3. List real alternatives.
4. Record consequences.
5. Link affected specs.

## Exit Criteria

- The change can be reviewed from repository content.
- Related specs, ADRs, RFCs, assets, and release notes are updated.
- The change is consistent with PL-OS Core.
