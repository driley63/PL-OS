# LIQ OS v1.7.0

Status: Released minor
Date: 2026-08-20

v1.7.0 releases the Capture-first Product Experience and compact surface milestone. It defines Capture, Habits, and Insights as connected product pillars; establishes the One Sentence Test for feature proposals; and adds implementation-ready behavior standards for widgets, shortcuts, wearable surfaces, one-tap Capture, Adaptive Capture, and learned habits.

## Included Areas

- LIQ OS Product Philosophy refinement for Capture, Habits, Insights, and the One Sentence Test
- Volume 02 Capture-first widget, shortcut, wearable, and compact-surface standards
- Stable anchors, adaptive suggestions, recent confirmation, overflow, privacy, and accessibility rules
- Volume 03 one-tap, guided, freeform, correction, backfill, and widget Capture behavior
- Adaptive Capture inputs based on frequency, recency, time, context, sequence, and user control
- Favorite Capture, learned habit, and dormant habit evolution rules
- Capture-to-Habits-to-Insights relationship and evidence expectations
- Feature-review requirements tied to user understanding, friction reduction, and the LifestyleIQ North Star
- MkDocs navigation and release index updates for v1.7.0

## Release Decision

This is a minor release because it adds new Product Experience and Design Language standards without breaking released Brand Identity, Engineering, AI, Architecture, Marketing, or Governance contracts.

## Known Limitations

- Standards are platform-neutral; exact iOS WidgetKit and Android widget-family dimensions and capabilities remain implementation decisions.
- Production capture catalogs, default values beyond Sleep and general Capture, deep-link routes, persistence, authentication, and sync contracts are not defined in this release.
- Production widgets, wearable components, interactive prototypes, and automated widget tests are not included.
